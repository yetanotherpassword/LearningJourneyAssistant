Classification rules

Each student × competency row gets one of four labels. The absolute rules are checked first, then whether the student's profile has enough spread for the relative rule, then the relative rule itself. MAD is the median absolute deviation of the student's own competency marks.

  1. Below {{ "%g"|format(rules.absolute_floor) }}% → gap (absolute floor), whatever the rest of the profile.
  2. At or above {{ "%g"|format(rules.absolute_ceiling) }}% → proficient (absolute ceiling).
  3. Fewer than {{ rules.min_competencies }} competencies, or a profile MAD below {{ "%g"|format(rules.min_spread) }} (a flat profile) → no relative judgement: at or above {{ "%g"|format(rules.fallback_proficient) }}% is proficient, below it developing (insufficient data).
  4. Otherwise, position = (mark − the student's median) ÷ MAD. At or below {{ "%g"|format(rules.relative_gap_cutoff) }} → gap; at or above {{ "%+g"|format(rules.relative_strong_cutoff) }} → proficient; between → developing (relative position).
  5. A gap evidenced in {{ rules.persistent_min_subjects }}+ subjects is persistent gap; in one subject, isolated gap.

Of the {{ gap_summary.gap_rows }} flagged rows, {{ gap_summary.basis_floor }} tripped the floor and {{ gap_summary.basis_relative }} the relative rule. A relative-only flag says which of a student's competencies are weakest, not that they failed anything.
