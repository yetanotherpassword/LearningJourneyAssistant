# Learning plan for STU0004

You're making steady progress across your subjects, with your strongest signals in the capstone (CSE3CAP) around Industry Standards and Project Management. The clearest area to focus on is Data Structures and Algorithms, which is a persistent gap, followed by consolidating your object-oriented foundations. These are formative signals to guide study, not a final judgement on your ability - the algorithms skills in particular build directly on your OO foundations, so working on both together will pay off.

## 1. Data Structures and Algorithms

**Evidence.** This is your lowest attainment at 48.9% and a persistent gap, with CSE2ALG at 48.0% (CSE1OOF 52.6%). Your CSE2ALG:Central examination (47.0%), CSE2ALG:Assignment (49.0%) and CSE2ALG:Test (49.0%) all sit in the limited range, and markers flagged gaps in identifying, implementing and comparing data structures and sorting/searching algorithms in Java.

**Actions.** Revisit the CSE2ALG:Central examination and CSE2ALG:Assignment feedback and re-attempt the tasks in smaller, well-tested pieces as the marker advised. Practise implementing searching and sorting algorithms in Java (CSE2ALG:SILO3), then explicitly compare their performance and justify a choice for a given problem (CSE2ALG:SILO4, CSE2ALG:SILO5). Anchor this by re-reviewing encapsulation and abstract data types from CSE1OOF:SILO2, which underpins clean data structure implementations.

Learning outcomes involved:
- `CSE1OOF:SILO2` -- abstract data types and encapsulation to localise and minimise change
- `CSE2ALG:SILO1` -- overall objectives of Algorithms and Data Structures
- `CSE2ALG:SILO2` -- identifying data structures and searching and sorting algorithms in computing contexts
- `CSE2ALG:SILO3` -- implementing data structures and searching and sorting algorithms in Java
- `CSE2ALG:SILO4` -- comparing algorithms and data structures and applying suitable choices to problems
- `CSE2ALG:SILO5` -- designing, implementing, and evaluating Java solutions using appropriate performance measures

Assessments to revisit: `CSE2ALG:Assignment`, `CSE2ALG:Central examination`, `CSE2ALG:Test`
