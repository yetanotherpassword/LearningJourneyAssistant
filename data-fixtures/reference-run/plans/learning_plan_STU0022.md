# Learning plan for STU0022

Your strongest areas are Project Management, Industry Standards Application, and Technical Communication (all 76%+), showing a solid foundation in professional software development practices. However, Data Structures and Algorithms (71.5%) and Object-Oriented Design (73.5%) remain gaps where consistent feedback highlights the need for clearer reasoning, more complete testing, and tighter links between decisions and implementation. Prioritizing these will build your core technical skills.

## 1. Data Structures and Algorithms

**Evidence.** Attainment 71.5% across CSE2ALG (71.0%) and CSE1OOF (73.5%), with consistent marker feedback across assessments (e.g., CSE2ALG:Central examination: "To strengthen the result, the student should provide clearer reasoning, improve technical precision and show more complete testing or reflection"), indicating persistent gaps in applying algorithms/data structures to problems.

**Actions.** Revisit CSE2ALG:Central examination feedback to practice justifying algorithm choices with performance measures; redo CSE2ALG:Test exercises on implementing data structures in Java with complete testing.

Learning outcomes involved:
- `CSE2ALG:SILO1` -- overall objectives of Algorithms and Data Structures
- `CSE2ALG:SILO2` -- identifying data structures and searching and sorting algorithms in computing contexts
- `CSE2ALG:SILO3` -- implementing data structures and searching and sorting algorithms in Java
- `CSE2ALG:SILO4` -- comparing algorithms and data structures and applying suitable choices to problems
- `CSE2ALG:SILO5` -- designing, implementing, and evaluating Java solutions using appropriate performance measures

Assessments to revisit: `CSE2ALG:Central examination`, `CSE2ALG:Assignment`, `CSE2ALG:Test`

## 2. Object-Oriented Design and Implementation

**Evidence.** Attainment 73.5% in CSE1OOF, with repeated feedback (e.g., CSE1OOF:Assignment: "Further improvement would come from deeper justification, more consistent evaluation evidence and tighter links between decisions and implementation details") across all assessments, indicating gaps in connecting design to implementation.

**Actions.** Re-examine CSE1OOF:Assignment feedback to strengthen links between object-oriented design decisions and code implementation; practice CSE1OOF:Test exercises on encapsulation with detailed reasoning.

Learning outcomes involved:
- `CSE1OOF:SILO1` -- analysis/design/implementation compared with object-oriented modelling using objects that combine data structure and behaviour
- `CSE1OOF:SILO3` -- code sharing and reuse through object-oriented techniques to reduce development time
- `CSE1OOF:SILO4` -- object-oriented design and implementation of computer programs for real-life problems

Assessments to revisit: `CSE1OOF:Assignment`, `CSE1OOF:Central examination`, `CSE1OOF:Practical demonstration`, `CSE1OOF:Test`
