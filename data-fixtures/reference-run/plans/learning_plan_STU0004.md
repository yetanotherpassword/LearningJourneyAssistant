## 1. Data Structures and Algorithms

**Evidence.** CSE2ALG assessments show persistent gaps in implementing data structures (47.0-49.0%) with feedback highlighting 'implementing data structures and searching and sorting algorithms in Java' and 'comparing algorithms' as key issues.

**Actions.** Revisit CSE2ALG:Test feedback on SILO3 implementation; practice Java exercises for sorting algorithms; review CSE2ALG:Assignment feedback on SILO5 performance measures.

Learning outcomes involved:
- `CSE2ALG:SILO3` -- implementing data structures and searching and sorting algorithms in Java
- `CSE2ALG:SILO4` -- comparing algorithms and data structures and applying suitable choices to problems
- `CSE2ALG:SILO5` -- designing, implementing, and evaluating Java solutions using appropriate performance measures

Assessments to revisit: `CSE2ALG:Test`, `CSE2ALG:Assignment`, `CSE2ALG:Central examination`

## 2. Object-Oriented Design and Implementation

**Evidence.** All CSE1OOF assessments (50.0-56.0%) show consistent gaps in 'abstract data types and encapsulation' and 'code sharing and reuse' with feedback emphasizing 'applying concepts more consistently'.

**Actions.** Revisit CSE1OOF:Assignment feedback on SILO2; redo practical exercises on encapsulation; review CSE1OOF:Test feedback on SILO3.

Learning outcomes involved:
- `CSE1OOF:SILO2` -- abstract data types and encapsulation to localise and minimise change
- `CSE1OOF:SILO3` -- code sharing and reuse through object-oriented techniques to reduce development time
- `CSE1OOF:SILO4` -- object-oriented design and implementation of computer programs for real-life problems

Assessments to revisit: `CSE1OOF:Assignment`, `CSE1OOF:Central examination`, `CSE1OOF:Practical demonstration`, `CSE1OOF:Test`

## 3. Technical Communication and Documentation

**Evidence.** CSE3CAP assessments (50.0-56.0%) indicate gaps in 'professional system documentation' and 'reporting outcomes' with feedback noting 'needs greater consistency' in technical reporting.

**Actions.** Revisit CSE3CAP:Assignment feedback on SILO4; practice documenting Java code; review CSE3CAP:Oral presentation feedback on SILO3.

Learning outcomes involved:
- `CSE3CAP:SILO3` -- reporting project outcomes to technical and non-technical audiences and reflecting on feedback
- `CSE3CAP:SILO4` -- professional system documentation and advanced technical reporting to industry standards

Assessments to revisit: `CSE3CAP:Assignment: Final written Project Report`, `CSE3CAP:Oral presentation: Final Project Presentation`
